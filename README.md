# The Lea Rig · Coffee & Pie

Concept website for The Lea Rig Café & Bakery, 127 Easter Road, Edinburgh.

A single static page (`index.html` + `img/`), no build step. Open `index.html` in a browser, or host it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Photos come from The Lea Rig's Instagram and Google listing. Get the owner's permission before you publish.
